法宝图标指纹提取工具

全流程：图库 → 标注 → 名录提取 → 回放 → 元素校准 → 保存。条目与校准样本存 localStorage（刷新不丢），truth 本体一律落盘为文件。

  • 图库：「选择图库目录」授权 test_images/（句柄缓存 IndexedDB 刷新自动恢复，失效点「恢复图库访问」重授）；保存 truth 直接写回 truth/<图片名>.json，不再弹保存框。
  • 标注：载入截图自动定位切格（失败可拖框 / 调整边界），逐件点选棋子，类型 / 品质 / 锚点自动填写可手改；名称候选唯一自动填入，歧义格跑整盘识别预填、 仍须从候选确认；草稿按图片名存 localStorage，「保存 truth」落盘 test_images/truth/。
  • 名录与提取：歧义组棋子行内「提取指纹」；名录顶部冲突组 「进入提取」下钻组级提取（采样 → 剔除 → 聚合 → 差分报告确认入库）； 0 样本法宝在提取页「手动补图」点选占用格补样本。
  • 回放：上传 truth + 截图（或图库一键载入）跑完整识别并对照 truth 评分，与 node tools/bench/bench.js compare 同口径；未配对 truth 的截图退化为纯识别回放。
  • 元素校准：批量载入 truth + 截图，先棋盘定位再按类别 展示锚点格卡片（采样圆盘范围，可拖动调圆心 / 改分类 / 舍弃）， 确认后按锚点格圆盘全像素采样（同 bench calib-dots 口径，圆心偏移写回 truth 持久化溯源），建议区间由簇分析自动产出 （两两零重叠，无需人工收窄），直方图对照后逐类 / 全部采用；采用与保存均过交叠硬校验，重叠即拒绝。
  • 并行：回放验证 / 元素校准素材定位与批量采样 / 组级提取批量采样均为 Web Worker 多图并行（识别口径与串行 / node bench 逐字节一致），顶部「并行线程」可调（默认 CPU 核数 - 2，下限 2，上限锁死为该默认值，存 localStorage）；worker 不可用自动回退串行。
  • 保存：输出整体替换 data/scan-fp-refs.js（Chromium 可「打开数据文件」授权直写）；保存成功后本地已提取条目自动清空 （内容已落盘），法宝名录 / 冲突组表格同步刷新为文件已存状态； SCAN_DOT_TYPES 变更入库后顶部出现重训提醒条，按提示在 tools/bench 重训（模型内嵌所对齐的区间水印）后「重新读取」校验一致自动解除。
  • Node 端（tools/bench/，项目根执行）：node tools/bench/bench.js run 全量回归 / compare 对照基线 / calib-dots 区间仿真校准；node tools/bench/refingerprint.js 批量重提指纹收紧组 maxDiff；模型重训序列 dump-feats.js && bench.js calib-types && dump-pixels.js && bench.js calib-pixel（BENCH_JOBS 调并发，模型采信 ovr 勿盲贴 tree，对照 data/scan-fp-refs.js 头注释）；node tools/test-fp-group.js 工具逻辑测试。
